As **CTO at Entriya** I architected a 12-layer autonomous drone software stack — ROS2 sensor fusion,
EKF state estimation, MPC control and consensus algorithms in an intent-to-command autonomy pipeline.
In drone autonomy a wrong assumption doesn't produce a bad metric, it produces a crash. That standard
carries into everything below.

**How I build:** the hard part — geometry, state machines, classifiers — stays pure and unit-tested
against inputs with known answers, so correctness is provable without hardware in the loop. Cameras,
models and databases plug in at the edges. Every repo ships with tests, CI and a README that documents
the limitations as plainly as the features.
